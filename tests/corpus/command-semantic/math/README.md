# TeX82 Math Semantic Minifixtures

This domain owns 11 tiny INITEX inputs for the audited TeX82 math properties in
§§699–767 and §§1136–1205. Each manifest case cites the complete exact section
range owned by its catalogue property and uses the generic
`execution-boundaries` projection. The short `math` directory declares its
catalogue owner explicitly as `math-box-list-and-mode-semantics`; discovery
still rejects any property owned by another shard.

The projection retains only requested committed boundaries. Expanded command
identities show the distinct math request path. Final box-register node outlines
cover field/atom, choice, and script construction without exposing arena IDs.
Mode transitions cover entry and exit lifecycle. The eight DVI-designated cases
also require a committed shipout artifact hash from
`MainControl::take_prepared_dvi_pages`, the focused boundary at which
the detached DVI page plan and page artifact have committed together.

Every source is one short line, needs no format or external font, and ends at a
box or shipout boundary. Cargo tests invoke no live TeX, distribution lookup, or
long document. Expected projections are exact passing observations; this domain
contains no ignored test or expected failure.
