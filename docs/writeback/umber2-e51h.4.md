# TeX82 filename and transcript-startup audit

Issue `umber2-e51h.4` audits tex.web §§511--538 against the local tree. The
canonical source is the pinned TeX Live 2025 `tex.web` identified by
`tests/tex82-properties/modules.json`; the reviewed spans are lines
9910--10414. This note distinguishes WEB bookkeeping from observable behavior
and does not treat Umber's typed host-resource envelope as if it were Pascal
file I/O.

## Audit result

The local evidence supports two new epic children: `umber2-e51h.105` for the
first-dot component mismatch and `umber2-e51h.106` for startup filename and
replacement acquisition. Existing issue `umber2-7e32` already precisely owns
the missing lazy DVI/transcript open and retry lifecycle, and
`umber2-alfh.15` owns loaded-format framing, so neither was duplicated.
Sections 511, 515, 521--523, 525's string-pool fallback, 528's zero sentinel,
and 533's output-handle initialization contain explanatory, representation,
or host-specific details with no additional Umber runtime observation.
