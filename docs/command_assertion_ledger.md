# Command Scanner and Delivery Assertion Ledger

Status: closed for `umber2-vgjr.15.3`

This ledger governs compaction of the active `tex-command` scanner and command-delivery tests. A test may be removed only when every assertion below has an active owner with the same authored input, operand, order, diagnostic text, lifecycle, rollback boundary, source context, and identity sensitivity. A digest, regenerated expectation, or helper self-test is not a replacement.

## Fresh-state contract

`test_harness::ProcessorScenario` owns one newly constructed `CommandState`, `Universe`, and `CommandHostCapabilities`. `ScannerRig` adds one new committed-observation recorder. Neither type is cached, cloned from a warm template, or shared between cases. Their fields remain visible to crate-internal tests so setup still mutates the exact state named by each assertion. The helpers only assemble the pre-existing constructor, ordinary transient token level, observer attachment, and diagnostic-channel projection.
