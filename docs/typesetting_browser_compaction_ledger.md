## Authorized Wire-Test Retirement

### `wire::tests::schema_one_tolerates_additive_fields_and_rejects_unsafe_integers`

- Accepting an unknown additive schema-1 option is owned by the active
  Firefox case
  `it::wire_schema_is_explicit_and_option_numbers_are_javascript_safe`. It
  sends `futureSchemaOneField` through `CompilerSession::new`, so it crosses
  the actual `JsValue` and binding boundary rather than only deserializing
  self-created JSON.
- Rejecting `9_007_199_254_740_992` as an unsafe `engineFuel` value is owned by
  the same Firefox case. It sends that exact first-unsafe integer through the
  public options object and requires the actionable safe-integer diagnostic.
- Disposition: delete the dormant ordinary Rust test. `umber-wasm` is excluded
  from `cargo test --tests`, and `scripts/check-wasm.sh` executes its
  `#[wasm_bindgen_test]` cases. The surviving case is both active and the
  stronger public-boundary proof. No digest, fixture generated by Umber, or
  declaration-only comparison substitutes for these assertions.
