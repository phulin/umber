# Runtime storage external contract ledger

Status: pre-rewrite semantic baseline for
[`runtime_storage_lifetimes.md`](runtime_storage_lifetimes.md).

This ledger freezes behavior that the runtime-storage rewrite must preserve.
The owners below assert TeX-visible channels, detached artifacts, host
protocols, or cold-run equivalence. Allocation order, pointer identity,
generation numbers, arena or region keys, owner counts, weak-index shape,
journal representation, and Rust type size are deliberately not compatibility
contracts.

## Deleted compatibility assertions

The following inventory is exhaustive for the outgoing live TeX runtime-value
ownership substrate. A surviving assertion may mention a generation, id, or
allocation only when it proves an independently required semantic boundary,
such as rejecting a foreign value before mutation; the old representation is
not its expected result.

| Deleted category                                  | Retired surfaces                                                                                                                                                                                                                                                                                               | Surviving contract                                                                                                                                                                                                                                      |
| ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Per-value `Arc`/`Weak` and pointer identity       | Strong/weak counts, pointer equality, clone/final-drop identity, weak metadata plateaus, exact structural-owner multiplicity, snapshot root sharing, and ownership-only source-descriptor reuse assertions were removed from `tex-state`, `tex-exec`, `tex-incr`, `umber`, and `benchmarks/tex-command`.       | Semantic values, independently mutable restored state, source identity, effects, artifacts, and allocation-independent node identity remain covered.                                                                                                    |
| Region keys and generation numbers                | Runtime-value region/registry suites, stale journal-generation assertions, layout-generation equality, VFS generation-number assertions in `umber`, exact region-coordinate restoration, and physical slot-reuse identity checks were removed.                                                                 | Rollback, fork isolation, snapshot restoration, changed-dependency fallback, and fresh loaded-job behavior remain observable without freezing a key representation.                                                                                     |
| Fabricated raw ids and private constructors       | Opaque-id raw-value/layout suites, synthetic node ids, unrooted private allocations, placeholder ids, and equal-slot fixtures whose only result was handle liveness were removed.                                                                                                                              | Production-created values still pass value round trips, foreign-value rejection at public mutation boundaries, portable format validation, and atomic failure tests.                                                                                    |
| Admission, root-set, and private-domain internals | Aggregate handle matrices, exact owner/admission error variants, root-set multiplicity and transfer projections, private-domain statistics, survivor pins, and testing-only root traversal or projection facades were removed.                                                                                 | Capability compile-fail tests, explicit semantic mutation APIs, checkpoint restoration, commit/rollback composition, and candidate acceptance/rejection remain covered.                                                                                 |
| Fixed layouts and handle or mark sizes            | Packed-id and coordinate width assertions, `CommandPreflight`, direct-operation mark, HotCore snapshot/stack/journal, fragment-handle, node-list-id, input-record, and `VirtualCompileSession` size ceilings were removed. The fixed HotCore snapshot benchmark crate was retired.                             | Portable wire/container geometry remains tested where it is an external ABI. Runtime structure layout may change freely; behavior is instead owned by format, retry, rollback, and artifact tests.                                                      |
| Lookup, reclamation, and physical growth          | Exact-candidate/weak-index lookup work, archive-coordinate reclamation, content-reuse candidates, liveness scans, exact chunk/region growth, retained-byte and owner-count accounting, generation charges, journal counts, ownership RSS plateaus, and `HOT_CORE_CENSUS` schema/count assertions were removed. | Semantic identity remains allocation-independent. Post-rewrite performance and bounded-memory requirements receive architecture-specific gates rather than compatibility assertions for the deleted mechanism.                                          |
| Ownership-only benchmark programs and rows        | `benchmarks/reachability-lookup`, `benchmarks/hot-core-snapshot`, `benchmarks/tex-command/benches/source_descriptor.rs`, and the `allocation_graph_transfer` and `survivor_root_recycling` `tex-state` rows were removed with their commands and operator documentation.                                       | Command allocation/packed-cutover, seven semantic snapshot workloads, format restoration, provenance budgets, dependency recording, accepted-edit scaling, typesetting, shipout, and pure-memo diagnostics remain available under their current owners. |

The audit deliberately excludes `Arc` sharing or buffer-reuse assertions in
host VFS, font decoding, bibliography, and pure typesetting components: those
values are not the live TeX runtime-value ownership substrate governed by
[`runtime_storage_lifetimes.md`](runtime_storage_lifetimes.md).

The composed-test changes which applied those categories were:

- `tex-exec` mode-summary tests no longer compare `Arc` pointers; they compare
  the preserved summary and independently mutated restored semantics. The
  stale journal-generation assertion was removed while nested rollback and
  non-innermost rejection remain covered.
- `tex-exec` transaction-protocol tests no longer pin `CommandPreflight` size,
  exact owner bitsets, mark projections, or owner/admission error variants.
  Exhaustive primitive classification remains.
- `EngineCheckpoint::has_exact_state_identity` and the `tex-incr` assertions
  that merely checked presence of an optional live-state identity were
  removed. Convergence now proves the selected boundary, reuse result, and
  byte-identical DVI.
- Synthetic private-revision probes, fabricated unrooted allocations, private
  domain statistics, exact ownership censuses, and layout-generation equality
  were removed from `tex-incr`. Retry and rejection tests instead compare
  accepted effects, artifacts, DVI, source layout, and checkpoint state.
- The long-session test no longer freezes live owner counts, weak-index bucket
  capacities, generation charges, journal counts, or RSS. It repeatedly proves
  cold semantic equivalence and stable work receipts across accepted and
  retried rejected revisions.
- The `VirtualCompileSession` Rust-size ceiling, VFS generation-number checks,
  and profiling `HOT_CORE_CENSUS` schema/count tests were removed from `umber`.
  Virtual compilation still proves atomic root/generated-file/output
  publication and exact rollback after failure.

These deletions intentionally leave no requirement to recreate the outgoing
`Arc`/`Weak`, region, census, generation-number, or fixed-layout substrate.
Performance and bounded-memory requirements belong to architecture-specific
post-rewrite gates, not to compatibility assertions about the old mechanism.
